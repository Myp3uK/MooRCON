# MooRCON

Консольный RCON-клиент с текстовым интерфейсом для управления игровыми серверами
по протоколу Source RCON. Хранит список серверов, историю команд по каждому серверу
и умеет автодополнять команды.

## Возможности

- **Список серверов** — добавление, редактирование и удаление подключений (адрес, порт, пароль).
- **Шифрование паролей** — пароли RCON хранятся зашифрованными через Windows DPAPI
  (per-user), а не в открытом виде. При вводе пароль маскируется.
- **REPL с удобным вводом** — редактор строки со стрелками ←/→, Home/End, историей
  команд (↑/↓) и автодополнением по Tab (список команд подтягивается с сервера через `help`).
- **История между сессиями** — команды сохраняются отдельно для каждого сервера.
- **Данные в %APPDATA%** — конфигурация и история лежат в `%APPDATA%\MooRCON`,
  а не рядом с exe. В меню есть пункт «Открыть папку с данными».
- **Безопасность сессии** — авто-отключение после 5 минут простоя, тайм-аут команды
  10 секунд, возврат в меню по `Ctrl+C`, до 3 попыток авторизации.

## Скачать

Готовые сборки под Windows публикуются в разделе [Releases](../../releases).
Для каждой версии собираются два варианта (для `x64` и `x86`):

| Файл | Описание |
|------|----------|
| `MooRCON-<версия>-win-<арх>.exe`                  | Компактный. **Требует установленного [.NET 10 Runtime](https://dotnet.microsoft.com/download)** |
| `MooRCON-<версия>-win-<арх>-self-contained.exe`   | Автономный (сжатый). Ничего доустанавливать не нужно |

Сборки создаются автоматически через GitHub Actions при публикации тега `v*`.

### О подписи

Бинарники **не имеют цифровой подписи** (code signing). При первом запуске скачанного
`.exe` Windows SmartScreen может показать предупреждение вида «Система Windows защитила
ваш компьютер / неизвестный издатель» — это ожидаемо для приложений без платного
сертификата и **не означает наличие вредоносного кода**.

Чтобы запустить: нажмите «Подробнее» → «Выполнить в любом случае». Если не доверяете
готовому файлу — соберите приложение из исходников самостоятельно (см. ниже).

## Требования

Для запуска — только Windows. Для сборки из исходников:

- [.NET 10 SDK](https://dotnet.microsoft.com/download)
- **Windows** — используется DPAPI для шифрования паролей и управление курсором консоли.

## Сборка и запуск

```bash
dotnet build -c Release
dotnet run -c Release
```

Или собрать самодостаточный exe:

```bash
dotnet publish -c Release -r win-x64 --self-contained
```

## Где хранятся данные

| Файл                          | Назначение                          |
|-------------------------------|-------------------------------------|
| `%APPDATA%\MooRCON\servers.json` | список серверов (пароли зашифрованы) |
| `%APPDATA%\MooRCON\history.json`  | история команд по серверам          |

## Стек

- [RconSharp](https://www.nuget.org/packages/RconSharp) — реализация протокола RCON.
- [Spectre.Console](https://spectreconsole.net/) — меню и оформление консоли.
