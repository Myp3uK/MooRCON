# MooRCON

RCON-клиент для управления игровыми серверами по протоколу Source RCON. Хранит список
серверов, историю команд по каждому серверу, шифрует пароли и умеет автодополнять команды.

Есть **две редакции**, использующие общее ядро и общие данные (`%APPDATA%\MooRCON`):

- **Консоль (TUI)** — лёгкий текстовый клиент в терминале (Spectre.Console).
- **Десктоп (WPF)** — оконное приложение с тёмной темой, вкладками и параллельными
  подключениями к нескольким серверам одновременно.

## Возможности

**Общее (обе редакции):**
- Список серверов: добавление, редактирование, удаление (адрес, порт, пароль).
- Шифрование паролей через Windows DPAPI (per-user), а не в открытом виде.
- Автодополнение команд (список подтягивается с сервера через `help`) и история ввода.
- История и настройки общие для обеих редакций (`%APPDATA%\MooRCON`).

**Десктоп (WPF) дополнительно:**
- **Вкладки** — несколько независимых подключений к разным серверам одновременно.
- **Keep-alive** — фоновое поддержание соединения живым (можно отключить на вкладку).
- Цветной вывод (команда/ответ/система), моноширинный шрифт, кастомная тёмная тема.

**Консоль дополнительно:**
- Редактор строки со стрелками ←/→, Home/End, авто-отключение по простою, возврат по `Ctrl+C`.

## Скачать

Готовые сборки под Windows публикуются в разделе [Releases](../../releases). Для каждой
версии собираются обе редакции (для `x64` и `x86`), по два варианта каждая:

| Файл | Редакция | Описание |
|------|----------|----------|
| `MooRCON-<версия>-console-win-<арх>.exe`                | Консоль | Требует [.NET 10 Runtime](https://dotnet.microsoft.com/download) |
| `MooRCON-<версия>-console-win-<арх>-self-contained.exe` | Консоль | Автономный, ничего доустанавливать не нужно |
| `MooRCON-<версия>-desktop-win-<арх>.exe`                | Десктоп | Требует [.NET 10 **Desktop** Runtime](https://dotnet.microsoft.com/download) |
| `MooRCON-<версия>-desktop-win-<арх>-self-contained.exe` | Десктоп | Автономный, ничего доустанавливать не нужно |

> **Какой рантайм нужен для `*-win-*.exe` (компактных):** консоли — обычный **.NET Runtime**,
> десктопу — **.NET Desktop Runtime** (включает WPF). Варианты `-self-contained` не требуют ничего.

Сборки создаются автоматически через GitHub Actions при публикации тега `v*`.

### О подписи

Бинарники **не имеют цифровой подписи** (code signing). При первом запуске Windows
SmartScreen может показать предупреждение «неизвестный издатель» — это ожидаемо для
приложений без платного сертификата и **не означает наличие вредоносного кода**.
Нажмите «Подробнее» → «Выполнить в любом случае», либо соберите из исходников.

## Требования для сборки

- [.NET 10 SDK](https://dotnet.microsoft.com/download)
- **Windows** — используется DPAPI (шифрование паролей), а десктоп-редакция — WPF.

## Сборка и запуск

Репозиторий — один solution из трёх проектов:

```
MooRCON.Core   — общее ядро (RCON, хранилище, DPAPI)
MooRCON.csproj — консольная редакция (TUI)
MooRCON.Wpf    — десктоп-редакция (WPF)
```

```bash
# консоль
dotnet run --project MooRCON.csproj -c Release

# десктоп
dotnet run --project MooRCON.Wpf -c Release
```

Самодостаточный exe (пример для десктопа, x64):

```bash
dotnet publish MooRCON.Wpf -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
```

## Где хранятся данные

| Файл                             | Назначение                           |
|----------------------------------|--------------------------------------|
| `%APPDATA%\MooRCON\servers.json` | список серверов (пароли зашифрованы) |
| `%APPDATA%\MooRCON\history.json` | история команд по серверам           |

## Стек

- [RconSharp](https://www.nuget.org/packages/RconSharp) — реализация протокола RCON.
- [Spectre.Console](https://spectreconsole.net/) — TUI консольной редакции.
- WPF (.NET) — десктоп-редакция.
